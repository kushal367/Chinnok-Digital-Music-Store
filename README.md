# Chinook PostgreSQL SQL Project

## Overview

SQL project analyzing a digital music store database using PostgreSQL. The project explores customers, invoices, tracks, artists, albums, genres, and purchasing patterns.

## Analysis

* Customer spending and purchases
* Popular and least popular genres
* Artists with the most albums and tracks
* Albums with fewer tracks
* Unpurchased tracks
* Customer and invoice analysis
* Average and highest-value tracks

## SQL Concepts Used

JOIN, LEFT JOIN, GROUP BY, HAVING, COUNT, SUM, AVG, MIN, MAX, CASE, subqueries, CTEs, and ORDER BY.

## Tools

* PostgreSQL
* SQL
* Chinook Database
